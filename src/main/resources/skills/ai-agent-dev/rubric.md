# AI Agent 开发证据评分规则

## 五级锚点

- 1 分：把 Agent 等同于一次 Prompt，无法说明系统边界。
- 2 分：知道组件和流程，但缺少评估或失败处理。
- 3 分：能设计基本状态、RAG 或工具流程并说明取舍。
- 4 分：能处理安全、评估、可观测性、延迟和成本。
- 5 分：形成质量可度量、故障可恢复、边界清晰的生产闭环。

## 证据规则

- 核验个人贡献、数据来源、评估口径和失败样本。
- 区分模型能力、系统能力和人工兜底效果。
- 参考资料不能替代候选人的设计依据和实践证据。

## 通用红旗

- RAG 只有向量检索，没有评估和溯源。
- 工具调用没有权限、沙箱或注入防护。
- 质量只凭主观体验判断。
- 只讲正常流程，不说明失败恢复。
